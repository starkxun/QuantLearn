## 怎么做

第 2 周只跑了一组参数（20/60）、一段区间（2022-2025）、一种成本设定，得出"收益
64.89%、跑输 BTC 但回撤更小"的结论。第 3 周要做的事，是**证明这个结论有多脆弱**。

要跑的组合数：3 组参数 × 训练/测试 2 段 × 有费/无费 2 种 = 12 次回测，再加上参数曲面
扫描的 80 多组。用 QC 回测界面一次次点显然不现实，所以：

| 工具 | 干什么 | 为什么 |
|---|---|---|
| [code.py](code.py) | Research notebook，向量化复现双均线，秒级跑完全部组合 | 快，且能画参数曲面 |
| [main.py](main.py) | 参数化的真引擎回测，跑 1~2 组 | 交叉验证向量化版本没算错 |

向量化版本自己承担了"不偷看未来"和"成本算对"的责任，所以 `code.py` 的 CELL 2 是全周
最需要读懂的地方，三条铁律：

1. 均线用 `rolling`，天然只看过去
2. **今天收盘算出的信号，最早只能赚到明天的收益** → `held = signal.shift(1)`
3. 每次换仓（0→1 或 1→0）扣一次单边成本 0.85%

漏掉第 2 条，回测收益会离谱地好——这本身就是"看起来赚钱"最经典的来源。

### 区间怎么拆

```
训练  2019-01-01 → 2023-01-01   （挑参数只能看这段）
测试  2023-01-01 → 2026-01-01   （挑完参数才允许看，只看一次）
```

规矩：**测试区间只能看一次**。如果看完发现不好，回去改参数再看第二次，测试集就已经
被污染成第二个训练集了——这正是过拟合的产生方式。

均线本身在全样本上滚动计算再切片。这不算偷看未来（SMA 只用过去数据），好处是测试区间
开头不会因为均线没预热而空掉一大段。

### 跑法

**A. Research notebook（主力）**

把 `code.py` 按 `# ---------- CELL n ----------` 分格粘进 `research.ipynb`，改顶部
CONFIG，逐格运行。CELL 3~6 直接输出验收要的所有表和图。

**B. 真引擎交叉验证（可选但推荐）**

`main.py` 全参数化，在 QC 的 Parameters 面板加 key：

| key | 值 | 说明 |
|---|---|---|
| `fast` / `slow` | `20` / `60` | 均线周期 |
| `start` / `end` | `2023-01-01` / `2026-01-01` | 换成训练区间就填 2019/2023 |
| `fees` | `1` 或 `0` | `0` = 零手续费零滑点对照组 |

跑同一组配置，和 notebook 的数字对一下。差几个百分点正常（成交时点、95% 仓位 vs 满仓、
逐笔手续费 vs 按比例扣），差一个数量级说明向量化版本写错了。

## 四个输出，对应四项任务

| CELL | 产出 | 对应任务 |
|---|---|---|
| 3 | 三组参数总表 + 手续费影响表 | ① 测参数 ③ 比成本 |
| 4 | 训练最优参数在测试集的排名 + Spearman ρ | ② 拆区间 ④ 记录是否仍有效 |
| 5 | 参数曲面热力图 / 训练-测试散点 / 净值曲线 / 费前费后柱状 | 全部 |
| 6 | 过关自检：自动判定有没有拿到过拟合或成本吞噬的证据 | 过关标准 |

**最关键的一张图是参数曲面热力图。** 判读方法：

- 训练图上的深蓝色如果是**一整片高原**，说明这个参数区间是真的有效，边上的参数也不差
- 如果只有**孤零零一格深蓝**，周围全是橙色，那就是拟合到了噪音——真实交易里差一天开仓
  结果就完全不同
- 训练图的深蓝区块，在测试图上**换了位置**，等于"最优参数"每段行情都不一样，等于没有
  最优参数

**Spearman ρ** 是同一件事的数字版：把所有参数按训练收益排名、按测试收益排名，两份排名
的相关性。ρ 接近 0 意味着训练集排名对测试集完全没有预测力。
