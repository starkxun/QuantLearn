### 关于滑点

```bash
滑点 = 实际成交价 - 预期价格

# 买入时（最常发生）：
预期价格：$100
实际成交价：$100.50
滑点 = $100.50 - $100 = $0.50（多付了0.5元）

# 卖出时（也会发生）：
预期价格：$100
实际成交价：$99.50
滑点 = $99.50 - $100 = -$0.50（少赚了0.5元）
```

**示例：**
```bash
# 理想情况
你看到牌子上写：白菜 2元/斤
你说："我要1斤"
商贩称好：2元
你付钱：2元
完全按预期价格成交

# 现实情况
你看到牌子上写：白菜 2元/斤
你说："我要100斤！"
商贩说："等等，你买太多了！刚才有人买走了50斤，现在只剩50斤了，
        而且因为你要得多，我得提价到2.2元/斤"
你最后付了：2.2元/斤
实际成交价比看到的价格贵了0.2元
```
